# SwiftCV

Free ATS-friendly resume & cover letter builder — 100% free, no signup, no backend.

🌐 **Live:** https://swiftcv.neocities.org/

## Features

- Resume builder with live preview (4 ATS-safe templates)
- ATS score checker with section-wise A–D grades
- Bullet Coach — scores every experience bullet, suggests specific fixes
- Job-description keyword matcher
- PDF CV import (parsed 100% client-side)
- Cover letter builder with fill-from-resume

## Tech

Vanilla HTML/CSS/JS. No framework, no build step, no server — everything runs in the
browser, and user data never leaves the device. Hosted free on Neocities.

## Files

- `index.html` — app markup + SEO meta
- `styles.css` — all styling
- `app.js` — builder logic, ATS scoring, PDF import
- `robots.txt`, `sitemap.xml` — SEO
